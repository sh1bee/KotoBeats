Mục tiêu dự án (Goal)
Ứng dụng học tiếng Nhật qua âm nhạc - sử dụng lời bài hát đồng bộ thời gian và phương pháp spaced repetition (SRS) với đoạn audio để tăng độ ghi nhớ từ vựng.

✅ Những gì đã có (Implemented Features)
1. Architecture & Navigation
App.tsx: Entry point với loading screen, thiết lập TrackPlayer
AppNavigator.tsx: 3-tab navigation (Home, Player, Profile) với custom blur tab bar
index.js: Đăng ký playback service
2. Audio System
trackPlayerService.ts: Setup TrackPlayer với setCommands() API v5
useAudioSync.ts: Hook đồng bộ vị trí playback, xử lý loop playback
cacheEngine.ts: Cache audio xuống thiết bị (downloadAsync)
playbackService.ts: Xử lý remote controls (play/pause/next/previous/stop)
@rntp/player.d.ts: Type definitions cho TrackPlayer
src/mocks/@rntp/player.web.ts: Mock cho web development
3. State Management (Zustand)
audioStore.ts: Quản lý currentSong, playlist, playbackPosition, isPlaying, loopInterval
flashcardStore.ts: Quản lý deck, xử lý swipe gesture cho SRS
4. Types & Data Models
LyricToken: word, base, romaji
LyricLine: lineId, startTime, endTime, text, translation, tokens
Song: _id, title, artist, coverUrl, audioUrl, duration, lyrics/lrc/lrcUrl
Flashcard: _id, word, reading, meaning, jlptLevel, snippetData, srs
SRSData: repetition, interval, easeFactor, nextReviewDate
5. Firebase Integration
config.ts: Khởi tạo Firebase app, auth (AsyncStorage persistence), firestore, storage
dbService.ts: CRUD operations cho songs và flashcards
6. Utilities
lrcParser.ts: Parse file LRC, tự động tính endTime dựa thời gian dòng tiếp theo, tokenize từ
srsEngine.ts: Thuật toán SuperMemo-2 cho tính toán ngày ôn tiếp theo
7. Screens
HomeScreen.tsx: Danh sách bài hát, SRS card preview, streak display
PlayerScreen.tsx:
Album art với animation xoay

Progress bar
Quiz mode từ vựng
Dictionary modal
ProfileScreen.tsx: Thống kê học tập, cài đặt
SRSFlashcardScreen.tsx: Flashcard với swipe gesture (Tinder-style)
8. Components
PlayerProgressBar.tsx: Thanh tiến trình với format thời gian, fallback khi native track duration lỗi
LyricLineUI.tsx: Hiển thị từng dòng lời, double-tap để seek
DictionaryModal.tsx: Modal từ điển Jisho
TinderCard.tsx: Flashcard swipe animation
PlayerProgressBar.tsx: Progress bar
